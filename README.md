Python Project (SNAKE GAME)
I just built SnakeGH, a classic Snake arcade game in Python!

In Lab 2 of my Python course at GCTU, I built a Tkinter game 
that:
✅
Moves the snake with the arrow keys or W A S D
✅
Grows the snake and adds points every time it eats
✅
Levels up and speeds up every 5 points
✅
Detects crashes into walls and into itself
✅
Saves my high score so it is still there next time
What I learnt:
• Drawing on a Tkinter Canvas with x and y coordinates
• Handling keyboard events
• How a game loop works with root.after(), and why a while loop would freeze 
the window
• Using lists of tuples and the global keyword to manage game state
Thanks to my lecturer for this fun hands-on lab.
